# shared · 跨工程共享定义

- **阶段**：P2 起
- **状态**：骨架，尚无代码

计划放置（**P2 才创建，现在不预留假接口**）：

| 文件 | 内容 |
|---|---|
| `protocol.h` | UART 定长帧结构、type 枚举、优先级定义 |
| `crc8.h` / `crc8.c` | CRC8（poly 0x07）查表实现 |
| `timestamp.h` | DWT 周期计数器封装、跨板时钟同步的往返时延估计 |

帧格式与消息类型见 [`../../docs/04_技术方案.md`](../../docs/04_技术方案.md) 第 4 节。
所有定义以该文档为准，改协议时文档与头文件必须同一次提交。
