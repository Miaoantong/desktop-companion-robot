# 10 · 电流触觉（实验工程）

- **阶段**：P1（2027.02 – 2027.04）· 项目第一个真创新点
- **状态**：骨架，尚未开始
- **目标**：双通道电流采样 → 4 类分类 → 摸头力度分级 / 柔顺退让 / 堵转保护
- **用到**：TIM 触发 ADC、DMA 双缓冲、决策树分类器、0.1Ω + MCP6002 差分放大
- **验收**：4 类准确率 ≥ 85%（自采 500 样本）、堵转检测 → 卸力 ≤ 200ms、60 秒 demo

**性质**：实验工程，可独立运行，代码可以乱；产品版在 `20_` / `90_` 里重构，不直接复制。
电路参数与特征定义见 [`../../docs/04_技术方案.md`](../../docs/04_技术方案.md) 第 2.2 节，
验收清单见 [`../../docs/01_项目规划.md`](../../docs/01_项目规划.md)。
