# firmware 代码目录

每个里程碑对应一个独立的 STM32 工程，方便回顾和对比。

## 里程碑01_表情脸

- 目标：OLED 上显示会眨眼、切换表情的脸
- 用到：I2C、SSD1306 OLED、表情库（RoboEyes）
- 完成后：把 CubeMX 工程放这里，保留 main.c 和说明

## 里程碑02_会转头

- 目标：双舵机云台上下左右转动，表情和动作联动
- 用到：定时器 PWM、舵机控制
- 完成后：把 CubeMX 工程放这里

## 提交约定

- 每个里程碑完成后，确保能编译、能运行，再提交一次 Git
- 提交信息示例：`完成里程碑1：OLED表情脸`
- 编译产生的垃圾文件已被 .gitignore 自动忽略，不用手动清理
