## 学习轨迹（保留，按里程碑编号）

### 里程碑01_表情脸

- 目标：OLED 上显示会眨眼、切换表情的脸
- 用到：I2C、SSD1306
- 完成后：CubeMX 工程放这里，保留 main.c 和说明

### 里程碑02_会转头

- 目标：双舵机云台上下左右转动，表情和动作联动
- 用到：定时器 PWM、舵机控制
- 完成后：CubeMX 工程放这里

## 产品轨迹（按阶段编号）

### 10_电流触觉（P1）

- 目标：双通道电流采样 + 4 类分类 + 摸头分级 + 堵转保护
- 用到：TIM 触发 ADC、DMA、决策树
- 验收：准确率 ≥85%，堵转卸力 ≤200ms

### 20_表情引擎v2（P0/P1）

- 目标：参数化矢量表情渲染，替代贴图切换
- 用到：6~8 个连续参数、脏矩形局部刷新、≥35fps
- 说明：从里程碑01 重构而来，产品版以此为准

### 90_v1_整合（P2 起）

- 目标：最终产品工程（L0 侧）
- 说明：会**重构掉**实验代码，不直接复制

### shared

- 跨工程共享的协议定义（`protocol.h`）、CRC 表、时间戳工具

## 约定

- 编号规则：`里程碑XX` 是学习轨迹，`XX_` 是产品轨迹，`90_` 是最终整合
- 实验工程可以乱，产品工程必须干净
- 每个里程碑完成后，确保能编译、能运行，再提交一次 Git
- 提交信息示例：`完成里程碑1：OLED表情脸`
- 编译产生的垃圾文件已被 `.gitignore` 自动忽略，不用手动清理
