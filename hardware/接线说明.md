# 接线说明

> 以下为推荐接线，引脚可在 CubeMX 中根据实际情况调整。
> 舵机工作电流较大，建议两块舵机使用**外部 5V 供电**，并与单片机共地，避免板载电源不稳导致重启。

## 0.96 寸 I2C OLED（SSD1306）

| OLED 引脚 | 接 STM32F103 | 说明 |
|-----------|-------------|------|
| VCC | 3.3V | 电源 |
| GND | GND | 地 |
| SCL | PB6 | I2C1 时钟线 |
| SDA | PB7 | I2C1 数据线 |

> I2C 地址通常为 0x3C（部分模块为 0x3D），驱动不显示时先检查地址。

## SG90 舵机 ×2（PWM 控制）

| 舵机 | 信号线 | 接 STM32F103 | 定时器通道 |
|------|--------|-------------|-----------|
| 舵机1（左右转头） | 橙色线 | PA0 | TIM2_CH1 |
| 舵机2（上下点头） | 橙色线 | PA1 | TIM2_CH2 |

| 舵机线 | 接 |
|--------|-----|
| 红色（VCC） | 外部 5V |
| 棕色（GND） | GND（与单片机共地） |
| 橙色（信号） | 对应 PWM 引脚 |

## 检查要点

1. 接线前先断电，避免短路。
2. 所有 GND 必须连在一起（共地），否则信号会乱。
3. 舵机转动异常 / 板子重启，多半是供电不足，优先检查电源。
4. 首次测试先让单个舵机小角度转动，确认正常后再装云台。
