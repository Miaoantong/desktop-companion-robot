## 2026-11-16

- 完成：写第一个不依赖 HAL 的模块 `app/protocol/`（CRC8 + 定长帧编解码），配 63 项 host 端断言，`make test` 秒级跑通
- 遇到的问题：本机没有 gcc / make，GitHub 直连只有 24KB/s（263MB 工具链要下 3 小时）
- 怎么解决的：改用 `pip install ziglang`（清华镜像秒装）当本地 C 编译器，命令与 gcc 一致；Makefile 留给 CI 用真 gcc 验证
- 结论：
  - **回环测试证明不了正确性**。做变异检验（把 CRC 多项式 0x07 改 0x1D），`suite_crc8` 红了但 `suite_frame` 全绿——编解码用同一个错多项式，roundtrip 依然自洽。只有标准校验值（`"123456789"` → `0xF4`）能抓住它
  - 逐字节状态机必须配「字节间超时复位」，否则半截帧会把下一帧的 `0xAA 0x55` 当 TYPE/LEN 吃掉，症状是偶发丢一整帧
  - `__DATE__` / `__TIME__` 会破坏可复现构建，clang 的 `-Wdate-time` 直接报错
- 下一步：装好 CubeMX 的 Makefile 工具链，把 `platform/` 生成出来，接 C1 的第一个功能
