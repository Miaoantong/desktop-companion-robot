## 立即采购（P1，约 10~15 元）

电流采样电路，用于"无传感器力感知"。

| 名称 | 型号 / 参数 | 数量 | 用途 |
|---|---|---|---|
| 采样电阻 | 0.1Ω ±1% 1W 金属膜 | 2 | 双路低边采样 |
| 运放 | **MCP6002**（轨到轨，DIP-8） | 1 | 差分放大 33 倍 |
| 电阻 | 1kΩ ±1% | 4 | 差分网络输入 |
| 电阻 | 32kΩ ±1%（或 33kΩ + 微调） | 4 | 反馈网络 |
| 电容 | 100nF | 4 | 电源去耦 |
| 电容 | 10μF | 2 | 采样输出滤波 |
| 洞洞板 | 5×7cm | 1 | 焊接采样电路 |
| 电源 | 5V/2A 适配器（或充电宝） | 1 | 舵机独立供电 |

> 选 MCP6002 而不是 LM358 的原因：LM358 不是轨到轨输出，且在 33 倍增益下带宽只有 ~30kHz，
> 电机换向的电流纹理会失真。MCP6002 贵不到 1 块钱，效果差很多。详见 `04_技术方案.md`。

## 供电注意（重要）

- SG90 堵转电流约 **700mA/个**，两个舵机 + MCU 峰值可能 > 1.5A
- **舵机必须走独立 5V 支路**，与 MCU **共地但不共用 USB 供电**
- 否则典型症状：一动舵机，MCU 复位 / OLED 花屏 / 串口乱码

```
5V/2A 适配器 ──┬── 舵机 1
               ├── 舵机 2
               └── (GND) ──┬── 采样电路
                           └── MCU GND  ← 必须共地
USB 5V ─────────── MCU VCC（仅逻辑供电）
```

## 主控分工

| 板 | 角色 | 时间尺度 |
|---|---|---|
| STM32F103C8T6 | L0 反射层：舵机环、电流采样、表情渲染、状态槽 | 微秒 ~ 10ms |
| ESP32-S3 | L1 感知层：唤醒词、雷达、声学、WiFi | 10 ~ 300ms |
| 笔记本（暂代） | L2 认知层：行为识别、记忆、主动策略 | 秒级 |

> 注：GPIO、I2C、PWM、中断、RTOS 等概念在各家 MCU 上通用，F103 上的外设经验可直接迁移到 ESP32。
