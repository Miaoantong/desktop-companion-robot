# 硬件清单

## 已备齐（阶段B）

| 硬件 | 型号 / 说明 | 用途 |
|------|------------|------|
| 主控板 | STM32F103C8T6 最小系统板 | 运行全部程序 |
| 显示屏 | 0.96 寸 I2C OLED（SSD1306，128×64） | 表情脸 |
| 舵机 | SG90 ×2 | 上下、左右转头 |
| 面包板 | 迷你面包板 | 搭建电路 |
| 杜邦线 | 公对母、公对公若干 | 连接各模块 |

## 阶段C再采购

| 硬件 | 型号 | 用途 |
|------|------|------|
| 麦克风 | INMP441（I2S） | 语音唤醒 |
| 触摸模块 | TTP223 | 摸头互动 |
| 副控板 | ESP32-S3 | 语音 / WiFi 处理 |

## 主控分工说明

- **阶段B**：全部用 STM32F103，跟协会学习，打牢 MCU 通用基础
- **阶段C**：语音 / WiFi 等联网功能交给 ESP32-S3（它自带 WiFi、蓝牙，适合做语音）
- 两块板之间通过串口（UART）通信

> 注：GPIO、I2C、PWM、中断、RTOS 这些概念在任何 MCU 上通用，
> 先用 STM32 学透，之后换 ESP32 会非常快。
