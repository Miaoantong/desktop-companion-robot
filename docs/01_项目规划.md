# 项目规划（v2 · 2026-11 定稿）

> 本文只回答"做什么、边界在哪、什么时候验收"。
> 实现细节与选型理由见 [`04_技术方案.md`](04_技术方案.md)。

---

## 1. 定位

> **一个隐私优先、慢脑 - 快反射架构的桌面具身智能体，聚焦学习场景下的在场感知与主动干预。**

由此推出三条判断标准，后续所有取舍都按它们走：

1. 评测标准是"**它能不能正确地不打扰你**"，不是"它聊得好不好"。
2. 技术重心在**实时性与决策**，不在模型大小。
3. 价值主张是**减少分心**，不是提供娱乐。

---

## 2. 功能边界

### v1.0 要做

- **在场感知**：雷达 + 声学判断"你在不在、坐了多久"，默认不采集图像
- **专注干预**：四级强度（沉默 / 微表情 / 动作+表情 / 语音）
- **触觉交互**：用舵机电流反推外力，做摸头力度分级与柔顺退让
- **表达一致性**：表情、转头、语调由同一个"情绪状态槽"派生
- **完全离线可运行**：断网、断连时降级但不崩

### v1.0 不做

| 不做 | 原因 |
|---|---|
| 通用对话（见下方"预留"） | 打不过大厂，且会稀释技术主线 |
| 情绪识别（判断你开不开心） | 学术上不可靠，真实场景准确率低，属伪科学重灾区 |
| 手机 App | 不服务于核心闭环 |
| 内置电池 | 续航会把项目拖死 |
| 堆砌传感器 | 每个都必须有闭环，否则不装 |

### 预留：对话模块（P4 可选）

定义为 L2 侧一个**可插拔的 dialogue provider**：

- 默认关闭，**不参与核心闭环**
- 接口只产出"话术文本"，**是否开口仍由主动策略决定**
- 目的是证明扩展性，不是做一个聊天机器人

> **判定标准：去掉它，项目依然完整；加上它，只多一个加分项。**

## 3. 阶段与验收

### P0（2026.11 – 2027.01）脸 + 脖子 + 可测量

按协会 STM32 外设进度走，学一个外设加一个功能：

| 序号 | 学习内容 | 机器人功能 |
|---|---|---|
| 1 | GPIO 输出 | 点灯、状态指示 |
| 2 | GPIO 输入 + 外部中断 | 按键有反应 |
| 3 | 串口 UART | 打印状态、调试 |
| 4 | 定时器 + PWM | 控制舵机角度 |
| 5 | I2C | 驱动 OLED 显示 |
| 6 | 参数化表情 + 双舵机 | 表情脸 + 转头联动 |

**验收**：
- [ ] 里程碑1：OLED 表情脸（眨眼、开心、睡觉）
- [ ] 里程碑2：会眨眼、会转头的小脑袋
- [ ] 表情改为**参数化渲染**（6~8 个连续参数，非贴图切换）
- [ ] 延迟测量框架：UART 打时间戳，能输出"触摸 → 表情"毫秒数
- [ ] README 里有第一份延迟数据

### P1（2027.02 – 2027.04）电流感知触觉 ★ 第一个真创新点

**验收**：
- [ ] 双通道电流采样：10kHz，TIM 触发 ADC + DMA 循环
- [ ] 四种波形可复现并截图：空载 / 轻触 / 推动 / 堵转
- [ ] 决策树分类器，4 类准确率 ≥ 85%（自采 500 样本）
- [ ] 摸头力度分级可用
- [ ] 堵转保护：检测到卡死 ≤ 200ms 自动卸力
- [ ] 60 秒 demo 视频

### P2（2027.05 – 2027.08）异构架构 + 隐私在场感知

**验收**：
- [ ] UART 协议跑通：定长帧 + CRC8 + 优先级 + 心跳
- [ ] 心跳超时 300ms → 舵机卸力、表情进入独立模式
- [ ] 跨板时钟同步（往返时延估计），能测端到端延迟
- [ ] ESP32-S3 端侧唤醒词跑通
- [ ] LD2410 在场检测，误报率 ≤ 10%

### P3（2027.09 – 2028.01）认知层

**验收**：
- [ ] 行为标签：在座 / 离开 / 看手机 / 低头 / 趴桌（不做情绪判断）
- [ ] 主动干预四级 + 打扰成本在线调整
- [ ] 记忆系统：遗忘曲线，跨会话回忆
- [ ] 干预接受率对比固定规则基线有提升

### P4（2028.02 – 2028.05）完整作品

**验收**：
- [ ] 外壳 + 完整整机
- [ ] benchmark 文档 + 消融实验
- [ ] 开源仓库（接线图、BOM、视频、README）
- [ ] 对话模块（可选）

## 4. 比赛映射

| 比赛 | 匹配度 | 说明 |
|---|---|---|
| 全国大学生嵌入式芯片与系统设计竞赛 | ★★★★★ | 最对口，STM32 + 边缘 AI |
| 全国大学生电子设计竞赛 | ★★★★☆ | 控制类题目能力可直接迁移；**奇数年举办，2027 年有** |
| RoboMaster | ★★★★☆ | 嵌入式 + 运动控制 + 视觉；JD 明确优先 |
| "挑战杯" / "互联网+" | ★★★☆☆ | 叙事好（隐私 + 学习场景），技术部分够硬 |
| 中国机器人大赛 / 服务机器人赛项 | ★★★☆☆ | 练手 |

> **注意 2027 年暑假可能撞期**：电赛与嵌入式竞赛时间接近，需提前确认赛程，二选一或分头准备。

## 5. 范围失控时的砍功能顺序

从先砍到后砍：

1. 对话模块（本来就是可选）
2. 人格漂移（保留纯记忆）
3. 主动策略的在线学习 → 退回固定规则 + 手动调参
4. 摄像头 → 只保留雷达（反而更符合隐私定位）
5. 总线舵机对比实验
6. 外壳（用亚克力 / 纸板）

**绝对不能砍的三件**——有这三个就足够拿奖 + 撑起简历：

> **电流触觉 + 隐私在场感知 + 慢脑快反射**
