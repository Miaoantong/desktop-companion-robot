# 项目规划

## 总目标

用一个**桌面陪伴机器人**，把嵌入式学习的全部知识点串起来，最终做出一个能陪学习、有长期记忆的作品。

## 阶段B（当前）：脸 + 脖子

跟协会 STM32 外设进度，学一个外设就加一个功能。

| 序号 | 学习内容 | 机器人功能 |
|------|---------|-----------|
| 1 | GPIO 输出 | 点灯、控制 |
| 2 | GPIO 输入 + 外部中断 | 按键 / 触摸有反应 |
| 3 | 串口 UART | 打印状态、调试 |
| 4 | 定时器 + PWM | 控制舵机角度 |
| 5 | I2C | 驱动 OLED 显示 |
| 6 | 表情库 + 双舵机 | 表情脸 + 转头联动 |

**里程碑1：OLED 表情脸**（眨眼、开心、睡觉）
**里程碑2：会眨眼、会转头的小脑袋**

## 阶段C（大二下）：感知 + 交互

- FreeRTOS 多任务（表情和动作并行）
- 本地语音唤醒（ESP-Skainet，离线）
- 触摸互动
- 学习专注功能：番茄钟、专注计时、久坐提醒
- WiFi 网页控制面板

## 阶段D（暑假~大三）：记忆 + 完整作品

- 3D 打印 / 毛绒外壳
- 长期记忆（边缘节点 + 向量数据库）
- 接入大模型对话
- 完整陪伴机器人 v1.0
- 同步学 Linux + ROS2

## 创新点（区别于普通教程）

普通教程做的是"标配身体"，本项目的差异在"大脑和关系"：

- 主动式交互：不是等指令，而是主动关怀
- 长期记忆：记得你的习惯、陪你一起成长
- 学习场景：专注于"学习搭档"这个具体场景
