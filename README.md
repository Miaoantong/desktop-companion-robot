# 桌面陪伴机器人 · Desktop Companion Robot

一个会眨眼、会转头、能陪你学习、未来还能记得你的桌面小机器人。

> 这是我的个人实践项目，也是我学习嵌入式 / 机器人开发的主线载体。
> 每学一个新外设，就给它加一个新本事。

---

## 它会长成什么样

| 阶段 | 能力 | 状态 |
|------|------|------|
| 阶段B | 有一张会眨眼的 OLED 表情脸，会转头 | 进行中 |
| 阶段C | 听得懂语音、能摸头互动、番茄钟 / 专注提醒 | 计划中 |
| 阶段D | 有长期记忆、能对话、有外壳的完整机器人 v1.0 | 计划中 |

最终定位：**学习专注搭档**——在你分心时提醒你，在你久坐时叫你休息，陪你度过每一个学习的夜晚。

---

## 硬件清单

- **主控**：STM32F103C8T6 最小系统板
- **显示**：0.96 寸 I2C OLED（SSD1306，128×64）
- **动作**：SG90 舵机 ×2（控制上下、左右转头）
- 阶段C 起：INMP441 麦克风、TTP223 触摸、ESP32-S3（语音 / WiFi）

详细接线见 [`hardware/接线说明.md`](hardware/接线说明.md)。
